本仓库力求在强化学习的学习过程中筑基坚实的数学原理，对每一个关系到实际算法理解、算法发展脉络以及算法实践的推导细节做详细注释（包含一些个人见解）；在重视推导细节的同时，本仓库也重视整个强化学习理论进化的脉络，一个总的梳理可以见 [强化学习纵览 ](./0_强化学习纵览.md) （还未整理完全）。强化学习是一门非常有趣的学科，它同时具有很强的理论性与丰富的实践性，是理论与实践的优雅结合，在学习强化学习的过程中，你既可以体会到数学理论的坚实，又可以惊叹于算法实践的巨大应用价值，可谓不得不品。

本仓库主要参考了西湖大学赵世钰老师的[《强化学习的数学原理》](https://www.bilibili.com/video/BV1sd4y167NS/)的课程和书籍，以及上海交通大学俞勇教授团队的[《动手学强化学习》](https://hrl.boyuai.com/)，以及其他各种网络资源。这些都是非常优秀的学习资源，在阅读本仓库前最好能过一遍这两门课程。

笔者想要特别强调，赵老师的课程真的是不可多得的好课。这是一门讲人话的课，任何一个学过基础数学的人都能从赵老师的课程中了解到强化学习的精髓，因为它实在是太入门友好、深入浅出了。赵老师非常重视数学原理的坚实性，没有任何一处不经介绍的假设、不带讲解的跳步，总是谆谆善诱。笔者最初只想把本仓库作为赵老师课程的一个课后笔记来整理，加入笔者个人对推导的理解。但后来发现，赵老师的课程只讲到 Actor-Critic 算法的理论就戛然而止了，后续对实践非常重要的诸多现代算法都未涉及，因此本仓库参考其他资源后，尽可能延续相似的风格，覆盖更多的现代算法。

LLM 时代让知识变得前所未有的触手可及，但从我个人的体验来看，利用 LLM 进行学习，总是一个 top-down 的过程，先有一个问题，LLM 解答它；LLM 的能力越来越强，可以解答得越来越清楚。但是，如果要系统地理解好一整门科学，bottom-up 的学习模式仍然是不可或缺的。
